七、日常更新流程

腾讯云云托管不像 Zeabur 那样支持 GitHub 推送自动部署。每次更新代码后需要：

1. 修改代码
2. 重新打包 zip（或用 Docker 镜像推送）
3. 在控制台新建版本 → 上传 → 部署
4. 等待新版本就绪，流量自动切换
如果觉得每次手动打包上传太麻烦，可以后续配置 CLI 工具 @cloudbase/cli，用命令行一键部署：
npm i -g @cloudbase/cli && tcb login && tcb fn deploy

附 C：常见问题

Q：构建失败，日志显示 "npm ERR!" ？

检查 Dockerfile 是否正确。确保 COPY package.json ./ 在 COPY . . 之前，这样 npm install 可以利用 Docker 缓存。

Q：部署成功后访问显示 502？

可能原因：
① 监听端口不匹配 — 确认版本配置中监听端口为 3000（和 server.js 一致）
② 环境变量未生效 — 确认 LLM_API_KEY 已配置并重新部署
③ 容器启动失败 — 查看日志排查错误

Q：第一次访问很慢（冷启动）？

正常现象。最小副本数为 0 时，没有请求时容器会被回收。第一次请求需要重新拉取镜像、启动容器，约 5-15 秒。后续请求就快了。

Q：如何更换模型？

在环境变量中添加 LLM_MODEL=你的模型名，重新部署新版本。

Q：能用自定义域名吗？

可以。在云托管 → 访问设置 → 自定义域名中添加。腾讯云默认域名不需要备案；如果你用自己的域名（如 .com/.cn），可能需要备案。
