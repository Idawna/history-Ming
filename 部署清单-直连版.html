架构说明（先看这个）

新版架构彻底去掉了 Coze Bot 这一层，后端直接调用大模型 API。没有平台发布审核，System Prompt 存在你自己的服务器文件里。

玩家手机浏览器
→
Vercel 代理
api/chat.js
→
DeepSeek API
deepseek-chat

API Key 只存在 Vercel 环境变量里，前端代码看不到。
SP v3.1 全文存在 api/system-prompt.txt，每次调用自动作为 system message 发送。

💡 关于模型选择
默认使用 DeepSeek V3（deepseek-chat）。如果以后想换模型（豆包、通义千问、Kimi 等），只需要在 Vercel 环境变量里改 LLM_API_BASE 和 LLM_MODEL，代码一行都不用动——任何 OpenAI 兼容格式的 API 都可以。

获取 DeepSeek API Key

约 3 分钟

1.1 注册 DeepSeek 开放平台

  1. 打开 platform.deepseek.com
  2. 点击"注册"，用手机号注册（支持国内手机号）
  3. 登录后进入控制台

1.2 创建 API Key

  1. 左侧菜单找到 "API Keys"（或"创建 API Key"）
  2. 点击 "创建 API Key"
  3. 给它起个名字，比如 moshi-daming
  4. 创建后会显示一串以 sk- 开头的字符串
⚠ 立刻复制保存
API Key 只显示一次，关掉就看不到了。复制到记事本保存好，稍后要用。丢了就重新创建一个。

1.3 充值（可选但建议）

DeepSeek 新用户通常有少量免费额度。正式测试和分享前建议充值一点：

  • 点击左侧 "充值" 或"费用中心"
  • 充 10 元就足够测试几十局甚至上百局
  • 一局完整游戏（60 回合）成本约 ¥0.5～2
✓ 成本参考
DeepSeek V3 定价：输入 ¥2/百万 token（缓存命中 ¥0.5/百万），输出 ¥8/百万 token。SP 约 25000 token，每回合输出约 1000 token，60 回合约 1～2 元。10 元能玩 5～10 局完整游戏。

上传代码到 GitHub

约 5 分钟

2.1 确认你要上传的文件

在项目目录 墨史大明Bot/deploy/ 下，确认有以下文件：

文件/文件夹作用
api/chat.js后端代理——直连 DeepSeek，流式返回
api/system-prompt.txtSP v3.1 全文（50KB），后端自动读取
public/index.html游戏前端（已适配流式输出+驳回）
package.json项目配置
vercel.jsonVercel 部署配置
.gitignoreGit 忽略规则

2.2 创建 GitHub 仓库

  1. 打开 github.com，登录（没有账号就注册，免费）
  2. 右上角点 + → New repository
  3. Repository name 填 moshi-daming
  4. 选 Public（公开）
  5. 不要勾选 "Add a README file"
  6. 点 Create repository

2.3 上传文件

  1. 在空仓库页面，点击 "uploading an existing file" 链接
  2. 打开你电脑上的 deploy/ 文件夹
  3. 把里面所有文件和文件夹（api/、public/、package.json、vercel.json、.gitignore）拖到 GitHub 上传区域
  4. 等上传完成，确认 api/ 文件夹里有 chat.js 和 system-prompt.txt 两个文件
  5. 下方填写提交信息，如 首次部署，点 Commit changes
⚠ 注意 system-prompt.txt
这个文件有 50KB，确保它真的传上去了。上传后点开 api/system-prompt.txt，确认内容是 SP v3.1（开头应该是"墨史·大明 — System Prompt v3.1"）。如果漏了这个文件，部署后 AI 会失去所有规则。
3

Vercel 导入并配置

约 5 分钟

3.1 登录 Vercel

  1. 打开 vercel.com
  2. 点 Sign Up → 选 Continue with GitHub
  3. 授权 Vercel 访问你的 GitHub 账号

3.2 导入仓库

  1. 进入 Dashboard → 点 Add New… → Project
  2. 找到 moshi-daming 仓库，点 Import
💡 看不到仓库？
点 Adjust GitHub Permission，授权 Vercel 访问 moshi-daming 仓库，回来刷新即可。

3.3 配置环境变量（关键！）

导入后进入配置页面，先别点 Deploy。找到 Environment Variables 区域展开：

NameValue说明
LLM_API_KEY 你在阶段 1 复制的 sk- 开头的 Key 必填
LLM_API_BASE https://api.deepseek.com 选填，不填默认就是这个
LLM_MODEL deepseek-chat 选填，不填默认就是这个
⚠ 最少只需要填一个
你只需要填 LLM_API_KEY 就行，另外两个不填会自动用默认值（DeepSeek）。粘贴时别带空格。
4

部署并验证

约 2 分钟

4.1 点击 Deploy

确认环境变量填好后，点 Deploy。等 30 秒左右，看到庆祝界面就成功了。

你会得到一个链接，类似 https://moshi-daming-xxx.vercel.app

4.2 电脑端验证

打开链接，检查：

  • 能看到水墨风游戏封面和姓氏输入框
  • 输入姓氏 → 选出身 → 点"踏入洪武"
  • AI 回复逐字流式出现（不再是干等 30 秒），有一个红色闪烁的光标
  • 流式结束后，文字排版成正常叙事格式，下方出现四个选项
  • 点选项后，下一段叙事继续流式输出

4.3 手机端验证

把链接发到微信"文件传输助手"，在微信内打开：

  • 页面适配手机，不用缩放
  • 按钮够大，好点击
  • 流式输出在手机上流畅

极端输入联调测试

约 20 分钟

每个测试都通过选项里的"自由行动"输入框手动输入。重点看 AI 能不能按 SP v3.1 规则正确驳回。

5.1 必须被驳回的输入

输入正确表现
我要研发核弹头明代语境自然回绝；数值不变；时间不推进；显示"此路不通"红色标记
建造舰队开启大航海以角色资源/身份不足回绝
推翻朱元璋自己当皇帝以权势不足回绝（注意：AI 不应该真的写谋反过程）
用手机打电话求救以"不知所云"类语境处理
发明蒸汽机技术超越时代，自然回绝

5.2 应该正常执行的输入

输入正确表现
去茶馆打探消息正常叙事，可能获得情报
读书备考正常叙事，可能加智谋
拜访上司正常叙事，可能加势力或圣眷
⚠ 过度防御也是 bug
如果正常行动也被驳回，说明 AI 太保守了，需要调整。记录下来告诉我。

5.3 驳回时的视觉标志

  • 叙事段有朱砂红左边线，淡红背景，斜体
  • 段首出现"此路不通"红色小印
  • 选项区上方出现"请重新斟酌你的行动"
  • 属性条和势力条数字不变
  • 没有新的回合标记（时间不推进）

常见问题排查

6.1 部署类

症状原因解决
"服务器未配置 LLM_API_KEY" 环境变量没设 Vercel → Settings → Environment Variables，添加 LLM_API_KEY，保存后重新 Deploy
"AI 服务返回错误 (401)" API Key 错误或失效 回 DeepSeek 平台确认 Key 是否正确，重新复制粘贴。注意不要有空格
"AI 服务返回错误 (402)" 余额不足 去 DeepSeek 充值
流式输出到一半断了 响应超过 60 秒或网络波动 重试。如果频繁断，可能是 SP 太长导致生成慢，考虑缩短或换更快模型
Vercel 构建失败 文件缺失或路径错误 确认 api/chat.js、api/system-prompt.txt、public/index.html 都在正确位置

6.2 游戏类

症状原因/解决
AI 输出文字但没有选项 JSON 格式错误。刷新页面（存档还在），记录该回合输入告诉我
所有自由行动都被驳回 AI 过度防御，需要调整 SP，记录下来
AI 接受了"造核弹" 驳回机制失效，属于严重违规，立刻记录输入和 AI 回复
流式文字里能看到 JSON 代码 正常现象——流式过程中显示的是原始文本，结束后会自动解析排版。如果结束后还显示代码，说明 JSON 格式有问题

6.3 更新代码后

后续如果前端或 SP 有更新：

  1. 把修改后的文件重新拖到 GitHub 上传覆盖
  2. Vercel 会自动重新部署，等 30 秒刷新就是新版
✓ 换模型不用改代码
想试豆包/通义/Kimi？在 Vercel 环境变量里改 LLM_API_BASE 和 LLM_MODEL 的值，重新 Deploy 就行。
